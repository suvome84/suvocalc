Matrix Calculator

The Matrix Calculator adds, subtracts, and multiplies 2×2 matrices, and calculates the determinant of Matrix A.

What it is used for

It is used by students to check matrix addition, subtraction, and multiplication homework, and to find determinants quickly while studying linear algebra.

Result

—

Formula

For 2×2 matrices: A + B adds matching entries. A − B subtracts them. A × B: entry (i, j) = row i of A multiplied by column j of B, added up. Determinant: det([[a, b], [c, d]]) = a×d − b×c.

Worked example

Inputs: Matrix A = [[1, 2], [3, 4]], Matrix B = [[5, 6], [7, 8]]. Addition: A + B = [[1+5, 2+6], [3+7, 4+8]] = [[6, 8], [10, 12]]. Multiplication: A × B = [[1×5+2×7, 1×6+2×8], [3×5+4×7, 3×6+4×8]] = [[19, 22], [43, 50]]. Determinant of A: det(A) = 1×4 − 2×3 = 4 − 6 = −2. Final results: A+B [[6, 8], [10, 12]], A×B [[19, 22], [43, 50]], det(A) = −2.

How to use

  1. Enter the four numbers of Matrix A in the 2×2 grid — the boxes start with 1 on the diagonal and 0 elsewhere.
  2. Enter the four numbers of Matrix B in the second 2×2 grid.
  3. Tap A+B to add, A−B to subtract, A×B to multiply, or det(A) for the determinant of A.
  4. Read the result shown in the result box below the buttons.
  5. Change any number and tap an operation again to recalculate.

Tips

  • Double-check the grid before calculating — one misplaced number changes the whole result.
  • Work through one small example by hand first so you can spot a wrong answer.
  • For multiplication, remember: rows of A times columns of B, then add.
  • If det(A) is zero, the matrix has no inverse — that is a useful check in linear algebra problems.

Common mistakes

  • Entering numbers in the wrong cells — row and column order matters in a matrix.
  • Multiplying matrices entry by entry instead of row-by-column, which gives a wrong product.
  • Expecting A×B to equal B×A — matrix multiplication is not commutative.
  • Forgetting that a matrix with determinant zero cannot be inverted.

Frequently asked questions

Does this calculator do 3×3 matrices?

The tool's grid is 2×2: two rows and two columns for each matrix. It offers addition, subtraction, multiplication, and the determinant of A.

Is A × B the same as B × A?

Yes. Matrix multiplication is not commutative — A×B and B×A usually give different answers, so the order matters.

What is a determinant?

The determinant is a single number that describes the matrix. For a 2×2 matrix [[a, b], [c, d]] it is a×d − b×c. A determinant of zero means the matrix has no inverse.
