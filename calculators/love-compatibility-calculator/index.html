Love Compatibility Calculator

The Love Compatibility Calculator plays the classic FLAMES name game with two names and gives one of six fun results. It is just for fun — for entertainment only, not a scientific result.

What it is used for

It is used for fun with friends: enter two names and see which FLAMES result the game gives — Friends, Love, Affection, Marriage, Enemies, or Siblings.

Formula

Method (FLAMES): write both names in lowercase with spaces removed. Cross out matching letters, one pair at a time. Count the letters left over. Starting from the list Friends, Love, Affection, Marriage, Enemies, Siblings, count around the list by that number and strike out the letter you land on, repeating until one word remains — that is the result.

Worked example

Inputs: Your Name Rahul, Partner's Name Priya. Step 1: remove the letters the two names share. Rahul is R, A, H, U, L and Priya is P, R, I, Y, A — the shared letters are R and A, one of each. Step 2: count the letters left over: H, U, L (3) plus P, I, Y (3) = 6. Step 3: use the count 6 to strike letters from the FLAMES list (Friends, Love, Affection, Marriage, Enemies, Siblings) in the tool's elimination order until one remains. Final result: Marriage. This is just for fun — for entertainment only, not a scientific result.

How to use

  1. Enter your name in the Your Name field, for example Rahul.
  2. Enter your partner's name in the Partner's Name field, for example Priya.
  3. Tap Calculate to see the FLAMES result.
  4. Read the short message shown under the result.
  5. Share it with friends for fun — and remember it is only a game.

Tips

  • Play it with friends and compare results — it is a party game, not a test.
  • Try both full names and nicknames to see how the result changes.
  • If the result is 'Enemies', laugh it off — the game has no power over real friendships.
  • Never let a fun result affect how you treat someone.

Common mistakes

  • Treating the result as a real prediction about a relationship.
  • Changing a name's spelling to get a nicer result and then believing it.
  • Using the result to make decisions about a real relationship.
  • Forgetting that the game only uses the letters in the names, nothing about the people.

Frequently asked questions

Is the FLAMES result real?

No. FLAMES is a playground game that counts leftover letters from two names. It says nothing real about a relationship — it is entertainment only.

What does FLAMES stand for?

FLAMES stands for Friends, Love, Affection, Marriage, Enemies, and Siblings — the six possible results of the game.

Does adding a middle name change the result?

No. Small changes to a name can change the count and therefore the result, which shows the result depends on spelling, not on the people.
