QR Code Scanner

The QR Code Scanner reads QR codes with your phone or computer camera, or from an uploaded image, and shows the text or link hidden inside.

What it is used for

It is used to read QR codes on posters, products, menus, and payment stands, and to check what a code contains before opening its link.

Camera view will appear here. Or choose an image file above.

Formula

Method: the tool reads frames from your camera (or a QR image you upload), looks for the square QR pattern, and decodes it back into the text, URL, or contact that was encoded. The result is shown with Copy and Open URL actions.

Worked example

Use case: scanning a QR code on a shop poster. Step 1: tap Start Camera and allow the camera permission — the camera preview appears in the frame. Step 2: hold the phone steady so the QR code sits inside the frame. Step 3: the tool reads the code and shows the decoded text in the result box, with Copy and Open URL buttons. Step 4: tap Copy to copy the text, or Open URL to visit the link — but read the address first. If the camera is not available, choose a QR image file instead using the upload field, and the tool decodes it the same way.

How to use

  1. Tap Start Camera to open the camera preview.
  2. Allow camera permission if the browser asks.
  3. Hold the QR code inside the frame until the result appears.
  4. Read the decoded text in the result box before doing anything with it.
  5. Tap Copy to copy the text, or Open URL if the address looks safe. Tap Stop when you are done.

Tips

  • Always read the decoded address before opening it — scammers hide fake links inside QR codes.
  • Hold the phone steady and keep the whole code in the frame.
  • In dim light, turn on your room light or move near a window instead of shaking the phone.
  • If the camera fails, take a clear photo of the code and upload it with the file field.

Common mistakes

  • Tapping Open URL without reading the address, which can lead to a fake or harmful site.
  • Holding the camera too close or too far, so the code is blurry or out of frame.
  • Scanning in poor light and assuming the code is broken.
  • Forgetting to tap Stop, which leaves the camera running.

Frequently asked questions

Can I scan a QR code from a saved photo?

Yes. If you cannot use the camera, use the 'Or upload QR image' field to pick a saved photo of a QR code, and the tool decodes it.

Does the scanner need camera permission?

The browser asks for camera permission when you tap Start Camera. Without permission the scanner cannot start, so allow it for this site only if you trust it.

Does the scanner check if a link is safe?

No. It only reads the pattern and shows the text or link. It does not check whether the link is safe — that is your job before tapping Open URL.
