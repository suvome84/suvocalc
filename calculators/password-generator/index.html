Password Generator

The Password Generator creates random passwords of a length you choose, mixing uppercase, lowercase, numbers, and symbols, with a strength indicator.

What it is used for

It is used to create random passwords for new accounts, replacing weak or reused passwords with a fresh one of a chosen length and character mix.

Formula

Method: the tool builds a character pool from the ticked options — Uppercase A–Z (26), Lowercase a–z (26), Numbers 0–9 (10), Symbols !@#$%^&*()_+-=[]{}|;:,.<>? (27) — then picks characters at random from the pool, one for each position, up to the chosen length (8 to 64). Strength score: one point each for mixed case, numbers, symbols, and length of 16 or more. Passwords are generated with the browser's built-in secure random generator (crypto.getRandomValues), and the result always contains at least one character from every character set you ticked.

Worked example

Use case: a password for a new email account. Settings: Password Length 16, with Uppercase, Lowercase, Numbers, and Symbols all ticked. Step 1: the tool builds a character set of 26 uppercase + 26 lowercase + 10 digits + 27 symbols = 89 characters. Step 2: it picks 16 characters at random from that set. Step 3: the strength bar reads full, because all four character types are on and the length is 16 or more. Final result: a 16-character password mixing all four character types, ready to copy. The tool does not store it, so save it in a password manager or write it down safely.

How to use

  1. Move the Password Length slider to your chosen length — 16 is the default.
  2. Tick or untick Uppercase (A-Z), Lowercase (a-z), Numbers (0-9), and Symbols (!@#$) as needed.
  3. Tap Generate to create a new password.
  4. Check the strength bar under the password.
  5. Tap Copy and paste the password into the account or your password manager.

Tips

  • Use a different password for every important account, especially email and banking.
  • Sixteen characters is a good default; go longer for accounts that hold money or personal data.
  • Store passwords in a password manager rather than in plain notes or photos.
  • Turn on two-factor authentication wherever it is offered — a strong password alone is not complete protection.
  • No password can be called unbreakable. A long, unique password plus two-factor authentication is the practical goal.

Common mistakes

  • Using a short password of 8 characters for an important account.
  • Unticking symbols and numbers, which shrinks the character pool and weakens the password.
  • Reusing the same generated password on several sites.
  • Generating a password and then forgetting to copy it before closing the page — the tool does not save it.

Frequently asked questions

How long should my password be?

Longer is better. Sixteen characters with all four character types is a good default; use 20 or more for important accounts like email and banking.

What does the strength bar mean?

The strength bar is based on which character types are ticked and whether the length is 16 or more. It is a rough guide, not a guarantee of safety.

Does the tool save my password?

No. The password is generated in your browser and shown on screen only. It is not saved anywhere by the tool, so copy it before leaving the page.
