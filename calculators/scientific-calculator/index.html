Scientific Calculator

The Scientific Calculator evaluates full mathematical expressions with brackets, powers, roots, and scientific functions — sin, cos, tan, log, ln, square root, factorial, and memory — in one place.

What it is used for

It is used by students and anyone doing maths, physics, or engineering homework to evaluate expressions with brackets, powers, roots, and trigonometric or logarithmic functions, and to check answers that a basic calculator cannot handle.

Formula

Expressions are evaluated with standard operator precedence: brackets first, then powers and roots, then multiplication and division (left to right), then addition and subtraction (left to right). Functions available: sin, cos, tan (in degrees), log (base 10), ln (natural log), square root, square (x²), cube, powers (x^y), factorial, 1/x, π, and memory (M+, MR, MC).

Worked example

Worked example: (45 + 15) × 3 − 100 ÷ 4. Step 1: work out the brackets first — 45 + 15 = 60. Step 2: multiply — 60 × 3 = 180. Step 3: divide — 100 ÷ 4 = 25. Step 4: subtract — 180 − 25 = 155. Final result: 155. A second example: sin(30°) = 0.5, log(100) = 2, and the square root of 144 = 12.

How to use

  1. Type or tap the digits and operators to build your expression — for example (45 + 15) × 3 − 100 ÷ 4.
  2. Use the bracket keys to group parts that must be worked out first.
  3. Tap a function key such as sin, cos, log, or √ to apply it to the number on screen.
  4. Tap = to evaluate the expression and see the result.
  5. Tap the Steps button to see the expression and result of the last calculation.
  6. Tap AC to clear everything, or the backspace key to delete the last character.

Tips

  • Use brackets liberally in long expressions — they make the order of calculation clear.
  • Check the steps view after a long calculation to confirm each part was evaluated as you intended.
  • Use memory (M+ and MR) to carry a result into your next calculation instead of retyping it.
  • For a quick check, test a function you know: sin(30°) should give 0.5 and log(100) should give 2.

Common mistakes

  • Forgetting brackets, so 45 + 15 × 3 is worked out as 45 + 45 = 90 instead of (45 + 15) × 3 = 180.
  • Using sin, cos, or tan with radians in mind — this calculator works in degrees.
  • Typing a power as 2^3 in the wrong place instead of using the x^y key.
  • Tapping = too early, before the whole expression is entered.

Frequently asked questions

Can I use brackets in an expression?

Yes. Tap the bracket keys to group part of an expression, for example (45 + 15) × 3. Everything inside brackets is worked out before the rest, following standard operator precedence.

Do sin, cos and tan use degrees or radians?

Trigonometric functions use degrees, so sin(30°) = 0.5. If you need radians, convert first: radians = degrees × π ÷ 180.

How does the memory work?

Tap M+ to add the current result to memory, MR to recall it, and MC to clear it. The memory badge on the display shows the stored value.

Can I see the steps of a calculation?

Tap the Steps button to show the steps of the last calculation. It shows the full expression and its result, which helps you check where a long calculation went wrong.
