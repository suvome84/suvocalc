Scientific Mode

SuvoCalc's Scientific Mode unlocks 15 advanced math functions. Tap the 🔬 flask button to activate.

sin, cos, tan

These work in degrees. Enter the angle first, then press the function.

sin(30°) = 0.5   cos(60°) = 0.5   tan(45°) = 1
Remember

SOH-CAH-TOA: Sine=Opposite/Hypotenuse, Cosine=Adjacent/Hypotenuse, Tangent=Opposite/Adjacent

log & ln

log = base-10. log(100)=2, log(1000)=3. ln = natural log. ln(e)=1.

Common Mistake

Never take log of 0 or a negative number — result is undefined.

Powers & Roots

Use xʸ: Enter 2 → xʸ → 10 → = → 1024.

2^10 = 1024   √144 = 12

Factorial n!

5! = 120. 10! = 3,628,800. Used in probability. Tip: 20! has 18 digits!

Pro Tip

Use x² for squaring (faster). Use 1/x for reciprocal. π = 3.14159..., e = 2.71828...
